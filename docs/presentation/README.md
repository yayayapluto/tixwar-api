# Presentation

Artefak presentasi dan laporan, dipisah dari dokumentasi teknis di `docs/`.

- `final-project-presentation.pdf` — deck final project (5 slide, Canva), yang dikumpulkan.
- `slide-tixwar.pptx` / `slide-tixwar.pdf` / `slide-tixwar.html` — pitch deck lama (12 slide).
- `slide-template.html` — template HTML pitch deck.
- `build-slides.py` dan `cdp-print.js` — script build pitch deck (one-off, menulis ke path absolut di luar repo).
- `demo-script.md` — naskah demo presentasi.
- `laporan-tixwar.md` / `laporan-tixwar.html` / `laporan-tixwar.pdf` — laporan TixWar.
